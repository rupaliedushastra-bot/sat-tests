### Question 1 (Module 1 · Q1)
**Topic:** `Linear Equations in One Variable`  

**Question:**
> If $4(2x - 5) = 3(x + 10)$, what is the value of $x$?

**Options:**
- **A)** $2$
- **B)** $5$
- **C)** $8$
- **D)** $10$ ✅ *(Correct Answer)*

**Correct Answer:** **D) $10$**

**Step-by-Step Explanation:**
Choice D is correct.

1. Pehle dono brackets expand karo:
$$4(2x - 5) = 8x - 20$$
$$3(x + 10) = 3x + 30$$

2. Equation ko solve karo ($x$ wale terms ek side, constants doosri side):
$$8x - 20 = 3x + 30$$
$$8x - 3x = 30 + 20$$
$$5x = 50 \implies x = 10$$

**Question:**
> If $3x + 2y = 18$ and $y = 2x - 5$, what is the value of $x$?

**Options:**
- **A)** $2$
- **B)** $3$
- **C)** $4$ ✅ *(Correct Answer)*
- **D)** $5$

**Step-by-Step Explanation:**

### Question 3 (Module 1 · Q3)

**Question:**
> The linear function $g$ passes through the points $(1, 4)$ and $(3, 10)$. If $g(x) = mx + b$, what is the value of $g(5)$?

**Options:**
- **A)** $13$
- **B)** $15$

- **D)** $18$

3. Ab $x = 5$ evaluate karo:
$$g(5) = 3(5) + 1 = 15 + 1 = 16$$

### Question 6 (Module 1 · Q6)
**Topic:** `Polynomial Operations`  

**Question:**
> The expression $(x + 3)(2x - 1) - (x - 2)(x + 4)$ is equivalent to $ax^2 + bx + c$. What is the value of $a + b + c$?

**Options:**
- **A)** $7$
- **B)** $8$

- **D)** $10$

- $(x + 3)(2x - 1) = 2x^2 - x + 6x - 3 = 2x^2 + 5x - 3$

3. Yahan $a = 1, b = 3, c = 5$:
$$a + b + c = 1 + 3 + 5 = 9$$

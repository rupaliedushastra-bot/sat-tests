### Question 1 (Module 1 · Q1)
**Topic:** `Linear Equations in One Variable`  

**Question:**
> If $4(2x - 5) = 3(x + 10)$, what is the value of $x$?

**Options:**
- **A)** $2$
- **B)** $5$
- **C)** $8$
- **D)** $10$ ✅ *(Correct Answer)*

**Correct Answer:** **D) $10$**

**Step-by-Step Explanation:**
Choice D is correct.

1. Expand both sides of the equation by distributing the coefficients:
$$4(2x - 5) = 8x - 20$$
$$3(x + 10) = 3x + 30$$

2. Set the expressions equal and solve for $x$:
$$8x - 20 = 3x + 30$$
$$8x - 3x = 30 + 20$$
$$5x = 50 \implies x = 10$$

### Question 6 (Module 1 · Q6)
**Topic:** `Polynomial Operations`  

**Question:**
> The expression $(x + 3)(2x - 1) - (x - 2)(x + 4)$ is equivalent to $ax^2 + bx + c$. What is the value of $a + b + c$?

**Options:**
- **A)** $7$
- **B)** $8$
- **C)** $9$ ✅ *(Correct Answer)*
- **D)** $10$

**Correct Answer:** **C) $9$**

**Step-by-Step Explanation:**
Choice C is correct.

1. Expand both expressions:
- $(x + 3)(2x - 1) = 2x^2 - x + 6x - 3 = 2x^2 + 5x - 3$
- $(x - 2)(x + 4) = x^2 + 4x - 2x - 8 = x^2 + 2x - 8$

2. Subtract the second expression from the first:
$$(2x^2 + 5x - 3) - (x^2 + 2x - 8) = x^2 + 3x + 5$$

3. Comparing with $ax^2 + bx + c$, we get $a = 1, b = 3, c = 5$:
$$a + b + c = 1 + 3 + 5 = 9$$
